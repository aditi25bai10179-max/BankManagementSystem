# Project Statement

## 1. Problem Statement

The **Bank Management System with Fraud-Check Simulation** is designed to provide a simple way to manage bank accounts and perform basic banking operations. It also helps identify potentially suspicious withdrawal transactions using simple rule-based fraud checks.

## 2. Scope of the Project

The project covers basic bank account management, including:

* Creating bank accounts
* Depositing money
* Withdrawing money
* Checking account balances
* Displaying account details
* Deleting accounts
* Maintaining withdrawal history
* Checking suspicious transactions
* Flagging accounts for review

The fraud-check feature is an educational simulation and is not intended for real-world banking security.

## 3. Target Users

* Students learning Java programming
* Beginners learning Object-Oriented Programming
* Users who want to demonstrate basic banking operations
* Academic project evaluators and instructors

## 4. High-Level Features

* **Account Management** – Create, view, and delete accounts.
* **Deposit & Withdrawal** – Perform basic banking transactions.
* **Balance Checking** – View the current account balance.
* **Transaction History** – Track withdrawal amounts.
* **Fraud Detection** – Identify potentially suspicious withdrawals.
* **Account Flagging** – Mark suspicious accounts for review.
* **Console Interface** – Simple menu-driven application.
